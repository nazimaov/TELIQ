## ru
- Приложение обновляет себя само: при запуске проверяет новую версию на GitHub и показывает «Что нового»; вручную — «Настройки → Проверить обновления»
- Избранное, история и скрытые каналы больше не пропадают, когда провайдер меняет токен в ссылках потоков
- В плеере в ряду «Избранное» у каждого канала кадр из эфира и что идёт сейчас; на выбранной ячейке кадры обновляются
- Пультом можно попасть на категории: «↑» с верха списка каналов
- Интерфейс плавнее на ТВ, плеер открывается и закрывается быстрее
## en
- The app now updates itself: it checks GitHub for a new version on start and shows "What's new"; manually via Settings → Check for updates
- Favorites, history and hidden channels no longer disappear when the provider changes the token in stream links
- In the player, each Favorites tile shows a live frame and what's on now; frames refresh on the selected tile
- Categories are reachable with the remote: press Up at the top of the channel list
- Smoother UI on TV, faster player open and close
